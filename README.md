# Learn JavaScript and Playwright

A collection of beginner-friendly JavaScript notes and examples. The repository is organized by topic and is intended for learning the language fundamentals before moving on to Playwright.

## Topics

- **JavaScript basics** — introductory examples
- **Keywords and identifiers** — reserved words, variable names, and naming rules
- **Literals** — numbers, strings, booleans, arrays, `null`, `undefined`, `BigInt`, and special numeric values
- **Operators** — arithmetic, assignment, comparison, and logical operators

## Getting started

Install [Node.js](https://nodejs.org/) to run the examples. Clone the repository, open a terminal in the project directory, and run an individual JavaScript file:

```sh
node "04_Operators/016_Logical.js"
```

Each file is a standalone example. Some files contain notes or demonstrations of particular values, so run examples individually rather than expecting a single application entry point.
